# Support FixMyType

FixMyType is a free, local, open-source accessibility utility. There are no ads, subscriptions, accounts, or paid local-core features. Donations pay for the practical work of maintaining a secure Windows app, testing hardware, reviewing issues, and keeping the project independent.

## Donate

**[Support FixMyType on GitHub Sponsors](https://github.com/sponsors/keesvanwanrooij)**

The donation link is voluntary. It does not unlock functionality, collect typing data, or change how the app treats you.

## Other ways to help

- Report a reproducible keyboard or application compatibility problem.
- Test a release on a Windows setup we do not yet cover.
- Improve Dutch or English interface wording.
- Review a documentation link or safety claim.
- Contribute a narrowly scoped, tested fix under [CONTRIBUTING.md](CONTRIBUTING.md).

For a project overview, return to [README.md](README.md); for documentation, use [docs/README.md](docs/README.md); for planned work, read [planning/README.md](planning/README.md).
