# Phase plans

This directory will contain one detailed plan for each approved FixMyType delivery phase. Read the [root README](../../README.md) for the public product promise, [docs/README.md](../../docs/README.md) for reference documentation, and [planning/ROADMAP.md](../ROADMAP.md) for the authoritative phase order.

Each phase plan must name its goal, user value, non-goals, dependencies, decisions, test-first tasks, automated checks, manual Windows checks, rollback path, and definition of done.
