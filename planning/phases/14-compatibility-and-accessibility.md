# Phase 14: compatibility and accessibility

## Goal

Verify the app with real Windows users, controls, languages, and assistive settings.

## Tasks

- [ ] Define the Windows test matrix.
- [ ] Test Dutch keyboard layout.
- [ ] Test English keyboard layout.
- [ ] Test keyboard-only navigation.
- [ ] Test screen-reader labels.
- [ ] Test 200 percent text scaling.
- [ ] Test high-contrast mode.
- [ ] Test browser controls.
- [ ] Test standard Win32 controls.
- [ ] Document exclusions and failures.

## Stop condition

Do not describe an untested application as compatible.
