# Phase 19: public release

## Goal

Publish a verified, installable, supportable release without overclaiming compatibility.

## Read first

All previous phase evidence, `README.md`, support policy, and release checklist.

## Tasks

- [ ] Confirm all prior phase criteria.
- [ ] Review repository for secrets.
- [ ] Review all public links.
- [ ] Update README status.
- [ ] Update installation instructions.
- [ ] Update changelog.
- [ ] Build installer and checksums.
- [ ] Create annotated release tag.
- [ ] Publish GitHub release notes.
- [ ] Monitor security and support routes.

## Acceptance criteria

The public release is installable, documented, checked, reversible, and supportable.

## Stop condition

Do not publish if any critical text-loss, security, or install defect remains open.
