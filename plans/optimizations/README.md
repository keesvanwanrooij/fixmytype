# Optimization plans

This directory records measured performance, reliability, accessibility, or resource-use improvements. Begin with the [root README](../../README.md), use [docs/README.md](../../docs/README.md) for product context, and check [plans/README.md](../README.md) before changing priorities.

No optimization is accepted on intuition alone. Record the baseline, the measurement method, the change, the result, and any regression risk. Text safety is never traded for speed.
