# Donations and sustainability

FixMyType’s local core remains free and open source. Donations are voluntary and never unlock a feature. **[Support FixMyType](https://github.com/sponsors/keesvanwanrooij)** helps fund maintenance, compatibility testing, and security updates.

Return to [README.md](../README.md), [docs hub](README.md), and [roadmap](../plans/README.md).

## Donation placement

Keep the Support FixMyType button at the bottom of the app and documentation entry points. It opens the fixed GitHub Sponsors address. It must not gate a feature, appear in the recording flow or imply a premium tier.

## Honest public claims

Describe the user's problem and show tested outcomes with supported contexts. Do not promise universal compatibility, perfect recognition or measured speed without evidence. A donor should understand what works today and what remains planned.

## Contributions beyond funding

Useful contributions include synthetic regression cases, verified Windows matrix rows, Dutch and English copy review, and reproducible performance measurements. Link each route from the root README and support guide.
