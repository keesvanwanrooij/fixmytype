# Privacy and data handling

FixMyType stores only local settings needed to run: enabled states, language preferences, sensitivity, exclusions, and local-model configuration. It does not store typed text, clipboard text, repair history, recordings, diagnostics containing characters, accounts, telemetry, or analytics.

Optional repair is sent only to a local Ollama endpoint selected by the user. If that endpoint is unavailable, the original text remains unchanged. A future feature cannot add network processing without a new explicit decision and privacy review.
