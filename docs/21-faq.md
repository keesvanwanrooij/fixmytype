# FAQ

**Does FixMyType send my text away?** No. The local core makes no cloud request. Optional repair uses a local Ollama service you select.

**Does it replace a keyboard?** No. It aims to reduce friction while you arrange a hardware fix or need an accessible fallback.

**Will every app work?** No claim is made until manually verified. Exclusions are available for uncertain contexts.
