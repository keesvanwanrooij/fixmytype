# FAQ

**Does FixMyType send my text away?** No. The local core makes no cloud request. Optional repair uses a local Ollama service you select.

**Does it replace a keyboard?** No. It aims to reduce friction while you arrange a hardware fix or need an accessible fallback.

**Will every app work?** No claim is made until manually verified. Exclusions are available for uncertain contexts.

See [README.md](../README.md), [docs hub](README.md), and [roadmap](../plans/README.md).

## Can it edit every Windows app?

Support is capability-specific. The internal editor can track its own revisions. Browsers, Word, Excel and terminals need separate adapter evidence. Unsupported targets receive proposals or drafts, not guessed historical replacements.

## Can it learn my voice and style?

The initial implementation uses a local approved style card and vocabulary. You can edit and delete both. Training a personalized model is not required for the first test version and will not happen silently.

## Can the companion listen and look all the time?

Capture requires an explicit session with visible scope and Stop. Personality does not change permissions. The companion can prepare a reply; sending it remains a deliberate user action.
