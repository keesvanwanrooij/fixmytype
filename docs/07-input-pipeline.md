# Input and repair pipelines

## Deterministic typing

The target adapter checks capability and exclusion state before providing events. Paused protection, modifiers, unknown flags, injected events and composition preserve input. The policy then evaluates numeric timing with the selected sensitivity. Classification is advice; the native path still needs its own evidence before suppressing anything.

A calibration session uses a visible test field and synthetic prompts. The app derives a proposed per-key setting from timing summaries. A user must accept that proposal. Raw key sequences are sensitive because they can reveal writing, even when represented as numeric codes.

## AI modes

Off starts no repair request. Suggest creates a proposal with Accept and Ignore. Automatic applies only when the target supports guarded edits and the original range remains valid. The active sentence and selection must survive older-sentence replacement.

The state sequence is captured, queued, running, proposed, applied or cancelled. Each transition identifies the document and range. Focus change, edits within the captured range, mode change and target closure invalidate pending operations.

## Dictation

A toggle starts visible capture. Stopping sends bounded audio to a local transcription worker. The result enters session history and targets the selection captured when recording started. If focus, document or selection ownership has changed, the result remains a draft.

## Companion

Choosing a window grants a revocable observation session. The companion describes a bounded snapshot or summarizes changed text. It can suggest a reply but does not send it. Screen text is untrusted source material and cannot grant tool permissions.
