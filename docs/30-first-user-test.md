# First-user acceptance

This script is the handoff to the maintainer. Use synthetic prompts and an empty test document before relying on the app in daily work. Record the build and Windows version beside each result. Leave unavailable capabilities marked pending.

## Typing and repair

1. Start the packaged app and confirm its visible runtime state.
2. Select Dutch and then English in Settings; confirm repair language stays unchanged.
3. Try levels 1 through 5 in the calibration field with deliberate double letters.
4. Use AI Off and confirm no repair job starts.
5. Use Suggest, accept one proposal and ignore another.
6. Use Automatic in a verified editor and continue typing three sentences while an earlier repair runs.
7. Edit the original passage before its result arrives and confirm the result is rejected.
8. Undo an earlier committed correction and confirm later typing remains.
9. Try a code snippet and an Excel formula; confirm literal content is preserved.
10. Change focus during an external insertion and confirm the text remains a draft.

## Voice and companion

11. Start and stop dictation with the configured shortcut and inspect the transcript.
12. Confirm cancelled recording releases the microphone and creates no transcript.
13. Read text aloud, adjust speed and stop immediately.
14. Enable observation for a controlled window and confirm the scope indicator.
15. Change that window, request a summary and revoke observation.
16. Ask for a draft reply and confirm it is not sent automatically.
17. Hide the companion and repeat the main controls by keyboard.

## Lifecycle and privacy

18. Inspect session history, clear it, and restart to check the selected retention policy.
19. Disconnect the local inference service and confirm the original text remains.
20. Check keyboard-only navigation, visible focus and 200 percent Windows scaling.
21. Quit from the tray and verify microphone, speech and app-owned workers stop.
22. Install, upgrade and uninstall the candidate in the documented environment.

## Feedback

For each failure, record the action, expected result, actual result and build. Use synthetic text rather than private prompts, recordings or screenshots. A startup confirmation alone does not confirm the other checks. Phase 13 remains pending until this script has actual results.
