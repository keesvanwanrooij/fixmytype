# Code of Conduct

FixMyType exists to reduce friction for people who need help typing. We want a community where people can ask basic questions, report accessibility needs, disagree about technical choices, and contribute without being dismissed or harassed.

## Expected behaviour

- Be respectful, specific, and patient.
- Critique code, claims, and decisions rather than people.
- Treat accessibility and privacy reports as useful product evidence.
- Respect requests to remove sensitive personal information from an issue or discussion.

## Unacceptable behaviour

Harassment, threats, discrimination, sexualised language, doxxing, deliberate disclosure of private text or recordings, and bad-faith disruption are not welcome.

## Enforcement

Report concerns privately through the repository’s security or maintainer contact route. The maintainer may clarify expectations, remove content, limit participation, or ban a participant when needed to protect the community.

This code is adapted for a small open-source project and applies to all repository spaces.
